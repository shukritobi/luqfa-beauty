# Official LUQFA photography source map

The demo embeds **direct original image URLs** published at https://luqfabeautyofficial.com/. These URLs have been extracted from the official pages, not invented or reproduced via image generation.

**Important:** Source files were not downloaded into this archive because network access in the packaging runtime blocks external binary downloads. Run `npm run assets` on a network-connected machine to copy these original image files into `assets/official/`; the downloader will update local image references automatically.
